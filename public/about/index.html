About this tool

BOM Component Description Enricher processes an uploaded Excel workbook one selected sheet at a time. Choose the part-number and description columns, then start the OpenRouter-backed description-enrichment workflow.

What happens next

  • Progress updates show how many rows have been processed.
  • A preview shows the original and enriched descriptions as rows complete.
  • When processing finishes, download the exported Excel file.

Local storage

Processed files are written to the running server's storage/results directory. Temporary files use storage/temp, and selected sheets are cached in memory during processing. These locations depend on the host's writable filesystem and are not permanent storage.
